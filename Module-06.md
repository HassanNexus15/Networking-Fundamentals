# Module 6 - Network Media

## Overview

This module introduces the different types of physical media used to transmit data across a network. It explains how twisted-pair, coaxial, and fiber-optic cables work, along with their advantages and common use cases.

# Twisted-Pair Cable

Twisted-pair cable is the most commonly used networking cable because Ethernet technology is widely used in local area networks (LANs).

## Characteristics

- Consists of pairs of copper wires twisted together.
- Twisting helps reduce electromagnetic interference (EMI) and crosstalk.
- Each wire pair is color-coded for easy identification.
- One wire is a solid color, while the other has the same color on a white background.

## Common Uses

- Ethernet LANs
- Home networks
- Office networks

---

# Coaxial Cable

Coaxial cable was one of the earliest network cable types and is still widely used in communication systems.

## Structure

A coaxial cable consists of:

- A solid copper core
- An insulating layer
- Braided metal shielding
- A protective outer jacket

The shielding protects the signal from electrical interference.

## Common Uses

- Cable television (TV)
- Internet provided through cable networks
- Satellite communication systems

---

# Fiber-Optic Cable

Fiber-optic cable uses light instead of electricity to transmit data.

It can be made from either:

- Glass
- Plastic

The fibers are approximately the diameter of a human hair.

## Advantages

- Extremely high transmission speeds.
- Supports communication over long distances.
- Immune to electromagnetic interference.
- More secure than copper cables because transmitting light is difficult to tap without disrupting the signal.

## Common Uses

- Internet backbone infrastructure
- Data centers
- Long-distance communication
- Medical imaging
- Medical treatment
- Mechanical engineering inspection

---

# Comparison of Network Media

| Cable Type | Transmission Medium | Advantages | Common Uses |
|------------|---------------------|------------|-------------|
| Twisted-Pair | Electrical Signals | Low cost, easy installation, widely used | Ethernet LANs |
| Coaxial | Electrical Signals | Better shielding than twisted-pair, supports broadband communication | Cable TV, Internet, Satellite |
| Fiber-Optic | Light | Very high speed, long distance, immune to interference | Data Centers, ISP Backbone, Enterprise Networks |

---

# Key Takeaways

- Twisted-pair cable is the most common cable used in Ethernet networks.
- Twisting the wires helps reduce interference and improve signal quality.
- Coaxial cable provides better shielding and is commonly used by cable TV providers.
- Fiber-optic cable transmits data using light, allowing for faster speeds and longer transmission distances.
- Different network media are selected based on cost, speed, distance, and resistance to interference.
